# 나라보다 하루 먼저 태어난 국회가 있었다

대한민국 임시의정원(1919)을 소개하는 기록 기반 인터랙티브 웹 콘텐츠입니다. 국회기록원 웹사이트 게재를 목표로, 중·고등학생 대상으로 제작했습니다.

## 파일 구성
- `assembly_archive_story.html` — 단일 HTML 인터랙티브 페이지 (반응형: PC/태블릿/모바일)
- `임시의정원_콘텐츠_제작노트.md` — 기획·제작 과정 기록 노트 (원자료, 콘텐츠 구조, 디자인 결정, 검증 내역)

## 콘텐츠 개요
1919년 4월 10일 임시의정원 개원이 4월 11일 대한민국 임시정부 수립보다 하루 빠르다는 사실을 훅으로, 임시정부와 임시의정원의 차이, 임시의정원의 탄생 과정, 주요 기능, 다섯 차례 헌법 개정, 정당 중심 좌우통합, 기록 발굴사, 오늘날 국회로 이어지는 계승 관계를 다루며 5문항 퀴즈로 마무리합니다.

## 원자료
